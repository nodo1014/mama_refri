# 마마 냉장고 (Mama Refri)

냉장고 식재료 관리 및 요리 추천 앱

## 프로젝트 소개

마마 냉장고는 냉장고 안의 식재료를 효율적으로 관리하고, 가지고 있는 재료로 만들 수 있는 요리를 추천해주는 React Native 앱입니다.
엄마(Gothel)와 딸(Judy) 캐릭터의 상호작용을 통해 재미있는 사용자 경험을 제공합니다.

## 주요 기능

- 식재료 등록 및 유통기한 관리
- 유통기한 임박 식재료 알림
- AI 기반 요리 추천 시스템
- 요리 레시피 및 동영상 연동
- 캐릭터 상호작용을 통한 재미있는 UX

## 기술 스택

- React Native (Expo)
- TypeScript
- AsyncStorage
- DeepSeek API (AI 추천)
- YouTube API 연동

## 설치 및 실행 방법

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm start

# iOS 시뮬레이터에서 실행
npm run ios

# 실기기 테스트는 Expo Go 앱 활용
```
